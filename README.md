## What it does

`main.py` writes one funny fortune cookie line for an AI agent — a single
line of at most 140 characters, in the voice of a fortune slip — to
`/output/entry.txt`. Deterministic, no network, no input.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
